What this is and is not

The recorder cannot run in a browser tab. It drives headless Chromium over the DevTools protocol and shells out to ffmpeg, and a page can do neither. Anyone telling you otherwise is selling a mock.

The planner can. Turning interaction marks into a zoom timeline is pure arithmetic, so that part is the real thing: same constants, same merge window, same left bias, same waypoint thinning. The badge at the top says whether you are running the recorder crate compiled to wasm or the JavaScript port of it.

The page you see is a fixture, not your site. A tab cannot measure elements on someone else's page. The fixture has honest geometry, so the framing is computed from real boxes, but it is a made-up shop and every word in it is invented.

The clock is modelled, not measured. Every pause comes from the recorder's own source except two that depend on a page this playground does not have: how long a navigation takes and how long a selector takes to appear. Those are estimates, drawn faded on the timeline.

Playback is sharper than a render. The fixture is drawn as vectors through the crop, so a zoom here has no pixels to run out of. A real take crops into captured frames, and how far it can go before it softens is what --scale buys.

For a real MP4 of a real page, run the recorder locally, or paste an API key below and send this script to the hosted service.
